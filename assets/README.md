# Brand assets

| File | Use |
|---|---|
| `dianemo-banner.webp` | 1200×511 — the README header |
| `dianemo-mark.png` | 256×256 — favicon, npm avatar, GitHub social preview |

Both are derived from the original generated PNG, which is kept outside the repo: 4.9 MB of raster
is not worth carrying in git history when the WebP is visually identical at a fraction of the size.

The banner has a light background, so GitHub's dark theme renders it as a light card.
